## How the course maps to these weeks

The slides were the source material; the [Notes](../01-notes/README.md) and [Exercises](../02-exercises/README.md) reorganize and expand that material into a topic-based reference that is easier to review and practice from.

- **Weeks 1–2** → Chapters 01–04 (setup, core language, control flow, functions)
- **Weeks 3–4** → Chapters 05–08 (data structures, comprehensions, file I/O, modules)

Start with the [Notes](../01-notes/README.md), practice with the [Exercises](../02-exercises/README.md), test yourself in the [Quiz Hub](../03-quiz/), and build something in [Projects](../04-projects/README.md).
